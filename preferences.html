RSO — Resync on Seek

Controls whether seeking within a song resends a MIDI GO command.
RSO OFF
Seeking between cues never sends a GO command to the console.
ONLY PLAY
Seeking between cues sends a GO command only while the song is playing.
ONLY STOP
Seeking between cues sends a GO command only while no song is playing.
Changes here take effect once you click Save below.

Video

Choose the display that video channels are projected on.
OUTPUT DISPLAY
Select the screen the audience sees. Video plays there full screen.
OUTPUT RESOLUTION
The size the video is rendered at on that display.
MATCH DISPLAY
Fills the display at its own resolution. Recommended.
3840 × 2160 (4K)
Renders at 4K, scaled to fit the display.
1920 × 1080 (Full HD)
Renders at 1080p, scaled to fit the display.
1280 × 720 (HD)
Lighter on the computer, for long shows or older machines.
FRAMING
FIT
Whole frame visible, black bars if the shape differs.
FILL
Fills the screen, cropping the edges.
STRETCH
Stretches to the screen, ignoring the aspect ratio.
Adding a video channel projects it automatically on the selected display. The screen icon on the channel still opens the small floating preview for the operator.

Timecode

Send MIDI Time Code (MTC) to the console alongside MSC cues.
MTC OUTPUT
OFF
No timecode is sent. MSC cues work as before.
ON
MTC follows the playhead on the MIDI output selected under MIDI. MSC cues keep firing too.
FRAME RATE
Must match the timecode setting on the console exactly.
24 fps
Film.
25 fps
PAL — the usual choice in Europe and Israel.
29.97 fps drop-frame
NTSC video.
30 fps
NTSC non-drop.
Each song is given its own hour (Song 1 = 01:00:00:00, Song 2 = 02:00:00:00 …) so timecode shows on the console never overlap. The hour stays with the song even if the running order changes, and can be changed in the song's controls in Edit Mode.

General

Auto Save and button password protection.
AUTO SAVE
Automatically save the current project in the background.
OFF
Auto Save is disabled — save manually with File → Save.
EVERY 1 MINUTE
Saves the project automatically once every minute.
EVERY 5 MINUTES
Saves the project automatically every 5 minutes.
EVERY 10 MINUTES
Saves the project automatically every 10 minutes.
Auto Save only writes to a project you've already saved once (File → Save or Save As) — it never opens a save dialog on its own, so it won't interrupt a show. Changes here take effect once you click Save below.
BUTTON PASSWORD
Protect critical buttons with a password.
Save Password
Remove Protection
When set, "PLAY ALL", the Cue Lock button, and the AMO (disconnect MIDI) button on the main screen will all ask for this password every time they're clicked. This applies immediately — it does not wait for Save.
